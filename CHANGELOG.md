## 3.1.0 — 28.10.2026: грабли без мусора, README для людей

Ставить ничего не надо — `git pull`. Старые грабли без счётчика просто начнут считаться с нуля.

**Что сделали:**
- **У граблей счётчик `(×N, дата)`** — сколько раз пригодилась и когда последний раз; пригодилась — +1 сразу. При
  выпуске версии грабли без счётчика или старше 6 месяцев — кандидаты на удаление (только с твоего «да»).
- **Фильтр перед записью грабли в общее** — три вопроса: знал бы и так? верно ли вне проекта? дорого стоила или
  повторится? Сомнение → в проект; в общее поднять, когда повторится в другом месте.
- **Вычистили грабли**, которые ассистент знает и так или которые были про старую машину и проекты Askend (14 штук:
  Spring 4.0, старый Gradle, сертификаты npm, ng-zorro, Docker Desktop, CRLF в Python и `sed` …). Грузится 68 КБ.
- **Словарик** — правило, как его вести: дописывать только по твоему сигналу («это я знаю») и только то, что иначе
  пришлось бы объяснять; больше 100 терминов — предупредить и предложить свернуть в темы.
- **`/ticket`, отчёт по факту** — план действий против факта: что сделано как задумали, иначе, отпало, добавилось — и
  почему.
- **README — для людей:** что даёт конфиг, каждая часть — коротким разделом с «Подробнее»; быстрый старт — «скачай и
  скажи Claude, где папка»; короткое дерево. **Техническое** — в `docs/`: как устроено, установка, дерево с размерами,
  настройки, строка состояния.

## 3.0 — 27.10.2026: короче и понятнее, личное вне репозитория

Переход с 2.x — `skills/rules/v2.2-to-v3.0.md`: `git pull` → `./install.sh --migrate` (в WSL ещё
`--private /mnt/c/Users/<user>/.claude/private`) → новые разделы профиля → в проектах проверить номера по таблице.

**Что сделали:**
- **Переписали все правила простыми словами** — «что → как → пример», без длинных абзацев. Грузится 72 КБ вместо 126.
- **Выкинули правила, которые повторяют то, что ассистент и так делает** (язык ответа, «коротко», «без
  снисходительности», временные файлы — в scratchpad, «не тянуть весь JSON» и т. п.), и мелкие грабли, которые видно по
  первой же ошибке. Похожие правила объединили в одно. Номера оставшихся не менялись — ссылки не ломаются.
- **Грабли записываем только ценные** — долго искали, часто повторяется или костыль в проекте (`FILES.WHERE.5`).
- **Работа с тикетом — один скилл `/ticket`, 8 шагов:** разбор → оценка → план → «делай» → отчёт по факту → что сказать
  и кому → оценка по факту → коммит → разбор сделанного. Из правил это ушло в скилл — грузится, только когда нужен.
  В `work.md` осталось то, что действует всегда: ветка, коммит, фоновые прогоны, сборка, замечания ревью.
- **Профиль, файлы фирм и `settings.json` — вне репозитория**, в `~/.claude/private`; в WSL — ссылка на папку Windows,
  те же файлы видны и оттуда. `git switch` их больше не затрёт. `install.sh`: `--private <папка>`, `--migrate`.
- **Выключить правило** — список в профиле (`USER.OFF`, `RULES.OFF.1`): номер или целый раздел; выключено проектное —
  работает общее.
- **Словарь в профиле:** термины, которые я знаю, — их не объяснять (`USER.ABOUT.5`); мои слова и что они значат —
  «делай», «меняй», «прогон» (`USER.ABOUT.6`). Пример в объяснении помечается `-------ПРИМЕР--------`.
- **Метка версии у грабли — со списком «где точно нет»** (`RULES.VER.1`): `[PostgreSQL 17–18; нет: PostgreSQL 15]`.
- **Новые утилиты:** `with-token.sh` — команда с токеном из `~/.bashrc`, значение не печатается; `session-time.py` —
  сколько часов ушло по сессии на разбор и на реализацию (для `/estimate`).
- **Скиллы** `/estimate`, `/commit-message`, `/review-lessons`, `/rules` переписали тем же стилем.
- **Новые грабли:** Windows-демон Gradle мешает сборке в WSL (`GRADL.TRAP.7`); пояс `Europe/Kiev` — и на
  PostgreSQL 17 (`SQL.TRAP.4`); сервер в WSL виден из Windows по `localhost` (`WSL.TRAP.3`); Rancher Desktop — как
  Docker Desktop, но `docker.exe` из Windows не работает (`WSL.TRAP.4`).
- **README** — только про текущее состояние; история — здесь, переход — в `v*-to-v*.md` (`RULES.EDIT.4`).
- Файлы сливать не стали: грузятся и так все, а «код файла = файл» удобен.

**Дальше:** примерно с 10.11.2026 — убрать всё по Askend (профиль, файл фирмы, `/timelog-askend` и его шаблон).
