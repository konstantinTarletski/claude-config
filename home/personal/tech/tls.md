# TLS — TLS и сертификаты

- **TLS.TRAP.1** Чужой сервис (шлюз, интеграция) отвечает `PKIX path building failed`, «раньше работало» → это ошибка
  TLS внутри того сервиса: в его truststore нет сертификата того, к кому он ходит дальше → не чинить у себя, передать
  сопровождающим (адрес и ошибка); проверить, не маскирует ли наше приложение это под бизнес-ошибку.
- **TLS.TRAP.2** Браузер открывает, а `curl` — «unable to get local issuer certificate», Java — `PKIX` → сервер не
  отдаёт промежуточный CA (браузер догружает сам) → `openssl s_client -connect <host>:443 -servername <host> -showcerts`
  (один сертификат, «Verify return code: 21») → чинит владелец сервера: полная цепочка.
