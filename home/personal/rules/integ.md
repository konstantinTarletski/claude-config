# INTEG — внешние системы: токены, трекер, wiki

Какие системы есть у фирмы и клиента, адреса, имена токенов — `FIRM`; готовые команды проекта — `INTEG` проекта.

- **INTEG.ALL.1** Токены → только в переменных окружения (`~/.bashrc`), только на чтение; в репозитории, в
  `claude-config` и в чате их нет (`SAFE.SECR.1`). Писать в трекер (статус, часы) → только по моему разрешению, потом
  перечитать и сверить.
  Утилиты (`jira.py`, `wiki.py`, `bb-pr.py`) берут токен из `~/.bashrc` сами; разовый запрос → `tools/with-token.sh
  <VAR> '<команда с $VAR>'`. Проверить токен → только длину.
- **INTEG.ALL.2** Имя токена → `<ФИРМА>_<СИСТЕМА>_TOKEN` (`ACME_JIRA_TOKEN`); у каждой системы свой. Адрес, если нужен
  утилитам, → `<ФИРМА>_<СИСТЕМА>_URL`.
- **INTEG.ALL.3** Положить токен → пользователь сам, в своём терминале (не через `!` — попадёт в чат):
  ```text
  read -rs T && echo "export <ИМЯ>='$T'" >> ~/.bashrc && unset T
  ```
- **INTEG.ALL.5** Внутренний сервис не ответил (таймаут, `Could not resolve host`, `Connection refused`) → первой строкой
  «⚠ <сервис> недоступен — похоже, слетел VPN» и ждать; не повторять в фоне, не продолжать молча на старых данных.
  Запросы — с таймаутом (`curl -m 20`).
- **INTEG.TRACK.2** Чего нет в тикете (Jira REST): история статусов → `/rest/api/2/issue/<KEY>?expand=changelog`; связанные
  PR и сборки → `/rest/dev-status/latest/issue/summary?issueId=<числовой id>`; задачи эпика → `/rest/api/2/search`,
  `jql="Epic Link" = <EPIC>` (в новых Jira — `parent = <EPIC>`).
- **INTEG.WIKI.2** Короткая ссылка Confluence `/x/XXXX` → id не виден: `curl -sSL -o /dev/null -w '%{url_effective}'
  <ссылка>` (с токеном) → в адресе `/pages/<id>/`.
- **INTEG.WIKI.3** Чего нет в тексте страницы (`body.storage`): диаграммы и картинки → вложения
  (`/rest/api/content/<id>/child/attachment`); тела код-блоков → в `<![CDATA[…]]>`; подстраницы → `/child/page`.
- **INTEG.WIKI.4** Изменения в спеке аналитик помечает цветом (новое — зелёным) и зачёркиванием → при выгрузке
  сохранять (`wiki.py`: `[+новое+]`, `~~убрано~~`), иначе зачёркнутое читается как действующее.
