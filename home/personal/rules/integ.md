# INTEG — внешние системы: трекер, wiki, git-сервер, почта, чат

Здесь — общее, верное в любой фирме. Какие системы есть у фирмы и клиента, адреса, имена токенов — `FIRM`
(`RULES.USER.2`); готовые команды, где в системе создаётся токен, грабли — `INTEG` проекта (`<repo>/.claude/integ.md`).

## INTEG.ALL — общее для всех систем

- **INTEG.ALL.1** Токены — **только в переменных окружения** (`~/.bashrc`), **только на чтение**. В репозитории, в
  `claude-config` и в чате их нет (`SAFE.SECR.1`); утилиты берут их из env. **Исключение — трекер, по моему
  разрешению** (`USER.PERM.2`): сменить статус тикета, записать часы (worklog). После записи — перечитать и сверить.
- **INTEG.ALL.2** **Имя токена: `<ФИРМА>_<СИСТЕМА>_TOKEN`** (`ACME_JIRA_TOKEN`, `ACME_TEAMS_TOKEN`). У каждой системы —
  свой токен (токен трекера на wiki обычно не работает). Адрес системы — так же: `<ФИРМА>_<СИСТЕМА>_URL`, если нужен
  утилитам.
- **INTEG.ALL.3** **Положить токен** — пользователь, в **своём** терминале (не через `!` — команда попадёт в чат), без
  следа в истории и на экране:
  ```text
  read -rs T && echo "export <ИМЯ>='$T'" >> ~/.bashrc && unset T
  ```
  `read -rs` — ввод не виден, `\` не портится; `>>` — дописать (один `>` затрёт файл); `unset` — убрать временную.
  Где в системе создаётся токен и с какими правами — `INTEG` проекта.
- **INTEG.ALL.4** **Подгрузить в сессию**, не печатая значение (`.bashrc` читается только при старте шелла —
  `WSL.TRAP.2`): `export VAR=$(bash -ic 'echo -n "$VAR"' 2>/dev/null)` в той же команде, где используется. Проверить —
  только длину: `echo ${#VAR}`.
- **INTEG.ALL.5** Запросы к внутренним сервисам — с таймаутом (`curl -m 20`). **Не ответило** (`Could not resolve
  host`, таймаут, `Connection refused`) — **первой строкой ответа** «⚠ <сервис> недоступен — похоже, слетел VPN» и
  ждать: не повторять в фоне, не ждать минутами, не продолжать молча на устаревших данных (локальные `origin/*`, старые
  выгрузки); если отвечаю без них — сказать, на чём основан ответ.
- **INTEG.ALL.6** Не тянуть весь JSON в контекст — только нужные поля (утилиты `personal/tools/`).

## INTEG.TRACK — трекер (Jira)

- **INTEG.TRACK.1** Тикет коротким текстом (статус, описание, комментарии, связи, вложения) — `tools/jira.py`.
- **INTEG.TRACK.2** Больше, чем описание: история статусов и полей — `/rest/api/2/issue/<KEY>?expand=changelog`;
  связанные PR/ветки/сборки — `/rest/dev-status/latest/issue/summary?issueId=<id>` (числовой id из `?fields=id`; без
  комментариев ревью); задачи эпика — `/rest/api/2/search` с `jql="Epic Link" = <EPIC>` (в новых Jira —
  `parent = <EPIC>`).

## INTEG.WIKI — wiki (Confluence)

- **INTEG.WIKI.1** Страница текстом — `tools/wiki.py` (принимает id или короткую ссылку `/x/…`).
- **INTEG.WIKI.2** Короткая ссылка `/x/XXXX` редиректит через `tinyurl.action`, id в ней не виден:
  `curl -sSL -o /dev/null -w '%{url_effective}' -H "Authorization: Bearer …" <ссылка>` → в URL `/pages/<id>/`.
- **INTEG.WIKI.3** Чего не видно в `body.storage`: (1) диаграммы (draw.io и т. п.) и картинки — **вложениями**
  (`/rest/api/content/<id>/child/attachment?expand=version`, свежие по дате; текст из `.drawio.svg` — регуляркой
  `>([^<>]+)<`, картинку — открыть); (2) тела код-блоков — в `<![CDATA[…]]>`, при вырезании тегов пропадают; (3) подстраницы —
  `/child/page`, предки — `?expand=ancestors`.
- **INTEG.WIKI.4** **Изменения в спеке** аналитик обычно помечает цветом (новое — зелёным) и зачёркиванием (`<s>` —
  убрано). При выгрузке сохранять пометки (`tools/wiki.py`: `[+новое+]`, `~~убрано~~`) — иначе зачёркнутое читается как
  действующее.

## INTEG.GIT — git-сервер (Bitbucket и т. п.)

- **INTEG.GIT.1** Комментарии, ревьюеры и статусы PR хранятся на сервере, не в git: SSH-ключ не поможет — только REST
  (с токеном) или UI. Нет токена — попросить у пользователя скриншот/текст комментариев. SSH-ключи не трогать.
- **INTEG.GIT.2** PR коротким текстом (статус, ветки, ревьюеры, сборка, комментарии) — `tools/bb-pr.py`. Bitbucket
  Server: `/rest/api/1.0/projects/<P>/repos/<R>/pull-requests/<N>[/activities]`, сборка —
  `/rest/build-status/1.0/commits/<hash>`.
- **INTEG.GIT.3** `fetch`/`pull`/`push` по HTTPS из WSL — Windows-git'ом (`GIT.TRAP.2`).
