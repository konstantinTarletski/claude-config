# SAFE — безопасность и аккуратность

## SAFE.SECR — секреты

- **SAFE.SECR.1** **Секреты не читать** — ни `cat`, ни `grep`: `~/.gradle/gradle.properties`, `~/.npmrc`, `~/.ssh/*`,
  `.credentials*`, `.env`. Наличие проверять `test -f`, значение переменной — не печатать. SSH-доступ (`ssh -T`) не
  проверять — пользователь делает это сам. Скопировать файл с секретами (в WSL-профиль и т.п.) — дать пользователю
  команду для `!`. Токены в чат не вставлять (в т.ч. в выводе команд). Как обращаться с токенами — `INTEG.ALL`.
- **SAFE.SECR.2** **Конфиги, где могут быть секреты** (`*.properties`, `*.yml`, `.env`) — печатать только имена ключей
  (`cut -d= -f1`), значение сверять по длине/хешу; не маскировать вывод регуляркой (префикс `grep -n` / другой формат
  строки — и маска молча не срабатывает).

## SAFE.OWN — чужое не трогать

- **SAFE.OWN.1** Чужие локальные изменения в рабочей копии (настройки разработчика, lock-файлы и т.п.) не трогать и в
  коммит не включать.
- **SAFE.OWN.2** **Свои папки пользователя** (общие папки, рабочий стол, документы — всё вне репозиториев и
  `claude-config`) — **писать туда только по его прямой просьбе** и только в названный файл; **предлагать
  скачать/положить туда файл — тоже нет**. Свои артефакты — по `FILES.DOCS`, временное — в scratchpad.

## SAFE.DESTR — разрушительные шаги

- **SAFE.DESTR.1** Удаление, перезапись, `rm`, `git rm`, переустановка зависимостей, скрипты, которые меняют файлы, —
  **отдельными командами**, не цепочкой `&&` с другими действиями. Перед — посмотреть цель (`git status`, `ls`,
  `--dry-run`), после каждого — проверить результат, и только потом следующий шаг.

## SAFE.PERM — меньше запросов разрешений

- **SAFE.PERM.1** Файлы править через Edit/Write (заметки, `CLAUDE.md`, `.claude/**`, `claude-config` разрешены без
  запроса в `~/.claude/settings.json`), а не через `python3` / `sed -i` / heredoc в Bash — каждая такая команда
  спрашивает разрешение; Edit сохраняет CRLF, а `sed -i` ещё и рвёт симлинки (`WSL.TRAP.8`).
- **SAFE.PERM.2** Чтение — простыми командами из разрешённого списка (`git status/log/diff/show`, `ls`, `grep`, `head`,
  `tail`, `sed -n`), не склеивать их в длинные цепочки с `cd`, `export`, `python3 -c`.
