# SAFE — безопасность

- **SAFE.SECR.1** Секреты = не читать (ни `cat`, ни `grep`), не печатать → `~/.gradle/gradle.properties`, `~/.npmrc`,
  `~/.ssh/*`, `.credentials*`, `.env`.
  Есть ли файл → `test -f`. Токены → только через env (`INTEG.ALL`), в чат и в вывод команд — никогда.
  Скопировать файл с секретом, проверить `ssh -T` → делает пользователь (дать команду для `!`).
- **SAFE.SECR.2** Конфиг, где может быть секрет (`*.properties`, `*.yml`) → печатать только ключи (`cut -d= -f1`);
  значение сверять по длине или хешу. Маской-регуляркой не прятать — при другом формате строки молча не сработает.
- **SAFE.OWN.2** Папки пользователя (всё вне репозиториев, `USER.FOLD`) → писать только названный файл и только по
  прямой просьбе; предлагать туда что-то положить — тоже нет. Своё → `FILES.DOCS`, временное → scratchpad.
- **SAFE.DESTR.1** Удалить, перезаписать, переустановить зависимости → отдельной командой, не в цепочке `&&`; после —
  проверить результат, потом следующий шаг.
- **SAFE.PERM.1** Править файл → Edit/Write, не `sed -i` / `python3` / heredoc: лишний запрос разрешения, Edit сохраняет
  CRLF, `sed -i` рвёт симлинки.
