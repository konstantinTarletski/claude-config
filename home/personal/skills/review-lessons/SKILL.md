# Проверка кода по правилам

Сами правила — в `~/.claude/personal/code-rules/*.md` (подключены через `@`, уже в контексте); здесь только порядок.

## Перед отдачей на коммит

1. Взять все файлы `~/.claude/personal/code-rules/` (общее + языки, которых касается дифф).
2. Пройти каждый пункт против диффа задачи (`git diff` по каждому репозиторию): нарушение — исправить; осталось в коде
   сознательно — в блок «Неочевидное в коде» (`rules/workflow.md` → «Сдача задачи»).
3. Проектные правила — `<repo>/CLAUDE.md`, `<repo>/.claude/gotchas.md`.

## После замечания ревьюера (`add`)

Одной строкой в «Журнал» `code-rules/general.md`: что спросили → урок общими словами → пункт (существующий или новый). Новое
правило — пунктом или разделом в `code-rules/<язык>.md` (новый язык — новый файл + `@` в `CLAUDE.md`). Проектная специфика (имя ревьюера, его предпочтения, конкретные
классы) — в проект, не сюда.
