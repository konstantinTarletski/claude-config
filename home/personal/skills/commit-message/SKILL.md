# Сообщение коммита

- **Стиль** → `WORK.DISC.4` проекта (формат `<KEY>: <суть>`, язык); нет → как 10 последних коммитов
  (`git log --oneline -10 --no-merges`) и одной строкой сказать, что взял из истории.
- **Ключ** → из аргумента, имени ветки или документа задачи. **Суть** → из диффа и `<repo>/.claude/tickets/<KEY>.md`,
  не по памяти.
- **Коротко (по умолчанию)** → одна строка `<KEY>: <что сделано>` — результат, а не «как» («окно детальных данных
  крона», не «добавлен компонент и метод»); без точки, до ~72 символов.
- **Длинно («длинный»)** → заголовок, пустая строка, 2–5 пунктов: что изменилось по частям (API, экран, тесты); почему
  так, если неочевидно; что сознательно не сделано. Без путей к файлам и списка тестов.
- **Несколько репозиториев** → сообщение на каждый, про его изменения.
- **Вывод** → в блоке списка на коммит (`WORK.DISC.6`): под `--------------- Commit message ------`, не на моём
  языке — с переводом (`COMM.LANG.3`).
