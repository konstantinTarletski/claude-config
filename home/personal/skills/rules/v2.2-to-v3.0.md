# Переезд с claude-config v2.2.x на v3.0 — короче, понятнее, личное вне репозитория

Читать при переезде (`RULES.MIGR.2`), не грузится всегда. Что поменялось — `CHANGELOG.md`, раздел 3.0. С 2.1 и раньше —
сначала `v2.1-to-v2.2.md`.

```text
1 на машине: личное → ~/.claude/private          (один раз, ./install.sh --migrate)
2 профиль: новые разделы                          (дописать руками)
3 в каждом проекте: номера, которых больше нет     (проверить grep'ом)
4 проверка
```

## 1. На машине — личное из репозитория в `~/.claude/private`

Было: профили, фирмы и `settings.json` лежали в `home/personal/users/` и `firms/` (скрыты `.gitignore`).
Стало: `~/.claude/private/users/` и `firms/` — вне репозитория, `git switch` их больше не затрёт (`GIT.TRAP.4`).

```bash
cd <claude-config>
git pull                                   # или git switch release-3.0, пока 3.0 не в main
./install.sh --dry-run --migrate           # посмотреть
./install.sh --migrate                     # Linux, Windows (Git Bash) — private станет папкой в ~/.claude
./install.sh --migrate --private /mnt/c/Users/<user>/.claude/private   # WSL — личное в папке Windows
```

`--migrate`: копирует `users/*` и `firms/*` в `private/` (своё не затирает), в профиле меняет строку
`@~/.claude/personal/firms/…` → `@~/.claude/private/firms/…`, переставляет `~/.claude/user.md` и `settings.json`.
Старое не удаляет: сверить (`cmp` по каждому файлу, отличается только строка фирмы) → потом
`rm -r home/personal/users home/personal/firms`.

## 2. Профиль — новые разделы (шаблон `templates/user.md`)

- `USER.ABOUT.5` — **термины, которые знаю**: не объяснять, только назвать.
- `USER.ABOUT.6` — **мои слова** и что значат («делай», «меняй», «прогон» …).
- `USER.OFF` — **выключенные правила** (`RULES.OFF.1`): номер (`COMM.EXPL.9`) или раздел (`WORK.EST`); выключено
  проектное — работает общее.
- По желанию — «как объяснять, чтобы я понял» (образец — формулы «X = что это → пример», пример помечать строкой
  `-------ПРИМЕР--------`).
- Ссылки в профиле на переехавшие правила: `WORK.EST` → `/ticket`, шаги 2 и 6; `WORK.DONE.3` → `/ticket`, шаг 8.

(`FILES.WHERE.1`). Метка версии в первой строке `CLAUDE.md` → `<!-- claude-config: 3.0 -->`.

## 4. Проверка

```bash
ls -la ~/.claude/user.md ~/.claude/settings.json ~/.claude/private   # ссылки → private
grep -n '^@~' ~/.claude/user.md                                       # @~/.claude/private/firms/<фирма>.md
ls <claude-config>/home/personal                                      # users/ и firms/ нет
```

Новая сессия Claude Code → спросить «какие у меня термины в профиле?» — ответит из `USER.ABOUT.5`, значит профиль
подхватился.
