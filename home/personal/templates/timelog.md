# Списание часов — настройки проекта (читает только `/timelog`, не `@`-импорт)

Шаблон — `personal/templates/timelog.md`; здесь только значения. Порядок работы — скилл `/timelog`; адреса трекеров и
токены — `INTG`. Общий для `<репозитории группы>`.

| Параметр | Значение |
|---|---|
| Трекеры | один — своя фирма / два — своя + клиента |
| Трекер своей фирмы | `INTG:<id>`; проект `<KEY>` |
| Трекер клиента | нет / `INTG:<id>` |
| Пары задач (два трекера) | `<наша задача>` ↔ `<задача клиента>` |
| Часов в день | `<у нас>` / `<у клиента>` (коэффициент) |
| Точность | целые / 0.25 |
| Язык описания | `<язык>` |
| Чем переносить | Atlassian-коннектор (MCP) / `tools/jira-worklog.py` |

## Куда писать часы

Схема фирмы или тимлида — коротко, с датой и от кого: подзадачи, куда нельзя (онбординг, оценки), исключения по задачам.

## Состояние

Перенесено в трекер по: `<дата>`; что не сверялось.
